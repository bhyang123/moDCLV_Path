# Licensing and redistribution

This release separates four decisions:

1. the license for the original moDCLV_Path code;
2. the terms for moDCLV_Path fusion and LoRA weights;
3. the Qwen3.5 base-model license; and
4. the access and use terms for UNI and QUILT-1M.

The code license is intentionally left pending in `LICENSE.pending.md` because no author-selected license was present in the source project. Add the intended license before making the repository public.

The [UNI model card](https://huggingface.co/MahmoodLab/UNI) describes gated access, non-commercial academic research use, attribution, and restrictions on redistribution. It also addresses derivatives trained on UNI outputs. Do not upload UNI weights or a UNI-derived adapter until the applicable terms have been checked for the intended release.

The [QUILT-1M repository](https://github.com/wisdomikezogwo/quilt1m) describes restricted data access and research-use conditions. Do not commit its images or restricted annotations here.

A Qwen license does not automatically determine the license of the combined VLM. State each component's terms and link to the original source.
